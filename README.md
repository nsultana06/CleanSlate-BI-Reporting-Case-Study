# CleanSlate — BI Reporting Case Study

## Tier 3 — BI Reporting Package

CleanSlate Cleaning Co. is a fictional small-business case study demonstrating an end-to-end business intelligence and reporting workflow using Microsoft Excel and Power Query.

The project transforms raw operational data into a validated analytical dataset, business insights, and an executive dashboard.

## Project Scope

- Data cleanup and standardization
- Data-quality assessment
- Validation and reconciliation
- KPI development
- Revenue and service analysis
- Payment analysis
- Customer analysis
- Operational analysis
- Business findings and recommendations
- Executive dashboard development

## Tools

- Microsoft Excel
- Power Query
- PivotTables
- Excel formulas
- Data validation and reconciliation
- Dashboard reporting

## Dataset

The dataset is entirely synthetic and contains:

- 7,500 job records
- 1,200 customer records
- 6 standardized service types

The data was intentionally designed to contain realistic data-quality issues for analysis and validation practice.

## Key Data-Quality Controls

The project evaluates:

- Duplicate Job IDs
- Missing Client IDs
- Invalid and future dates
- Missing and negative invoice amounts
- Invalid hours
- Missing cleaner values
- Payment-status inconsistencies
- Customer ID relationships
- Service-type standardization
- Preservation of source record counts and financial values

Business-data exceptions that could not be objectively corrected were retained and flagged rather than deleted.

## Key Business Findings

The analysis identified:

- Post-Construction Clean as the strongest revenue-generating service.
- Recurring Clean as a high-volume service with comparatively low revenue per job.
- Leander as the strongest service area by both revenue and job volume.
- A material difference between invoiced revenue and recorded payments.
- Strong repeat-customer activity across the customer base.

## Data Treatment

The project follows a controlled data-cleaning approach:

> Clean what is objectively cleanable; flag what cannot be safely determined; retain the record; proceed with analysis; disclose limitations.

Negative values, missing values, duplicate records with differing details, and other unresolved business-data exceptions were not arbitrarily removed.
